Force Icon Mod (1.0) - File Description

Description:

A small mini-mod that replaces the Force power icons on the in-game HUD with the artwork from the single-player Force upgrade menu. Nothing else is touched, so it runs in both single-player and multiplayer without conflicts.

Force Icon Mod (1.0) - Readme

Readme File:

Jedi Knight: Jedi Academy
==================================

Title:          Force Icon Mod
Author:         Gamma097
File name:      G7_forceiconmod_JK3.pk3
Size:           1.28 MB (compressed and uncompressed)
Released:       June 30, 2011

Description
Swaps the Force power HUD icons for the single-player upgrade menu
artwork. Works in single-player and multiplayer.

Installation
Copy G7_forceiconmod_JK3.pk3 into the GameData/base folder of your
Jedi Academy install.

Uninstallation
Delete or move G7_forceiconmod_JK3.pk3 out of GameData/base.

Known bugs
None. Only a handful of image files are replaced.

Permissions
Contact the author before reusing this mod in another project.

This modification is not made, distributed or supported by the game's
publisher or developers.
